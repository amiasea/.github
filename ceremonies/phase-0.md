# Phase 0 — Enterprise Establishment (Manual)

These are enterprise acquisition and ownership ceremonies.

They establish the external platforms, accounts, and organizational boundaries required for the Amiasea operating model.

These ceremonies happen once and are performed manually.

## Cloud Provider Establishment

### Azure

* Azure account creation.
* Azure primary subscription acquisition.

### AWS

* AWS account creation.

### Google Cloud

* Google Cloud organization establishment.
* Google Cloud billing establishment.
* Google Cloud project establishment.

## Platform Establishment

### HCP Terraform

* HCP Terraform Enterprise establishment.
* HCP Terraform organization creation.

### GitHub

* GitHub personal account creation.
* GitHub Enterprise creation.
* GitHub Organization creation.

## Output

At the completion of Phase 0:

* Cloud provider ownership exists.
* Platform ownership exists.
* Required enterprise accounts exist.
* Administrative boundaries exist.

These ceremonies establish the foundation for automated bootstrap.

Terraform does not automate these activities.
