# Enterprise Portfolio

The Enterprise Portfolio is the enterprise orchestration boundary.

It is an operational Terraform stack responsible for composing enterprise realization and controlling execution.

The Enterprise Portfolio:

* References versioned Enterprise Initiative SCCs.
* Establishes upstream Strata Base Stack relationships.
* Supplies required foundation context.
* Provides deployment environments.
* Owns approval boundaries.
* Owns execution history and operational reckoning.

The Enterprise Portfolio is the deployment execution boundary.

It determines when enterprise realization proceeds through approved execution.

The Enterprise Portfolio does not define:

* Application implementation.
* Organizational assembly logic.
* Vendor-specific runtime implementation.

The Enterprise Portfolio coordinates realization.

It does not implement realization details.
